FTI Studio Major Update: New Tools and Features

FTI Studio

October 5th, 2026

FTI Studio just received its biggest update yet. What started as a focused Windows image editor built around the .fti format has grown into a noticeably more capable tool without losing the lightweight feel that defined it from the beginning.

A quick reminder of what FTI Studio actually is: it is a native Windows-only image editor with transparency included. The name Flat Transparency Image (.fti) simply means a straightforward 2D image format that stores a full alpha channel. It is not a specialized transparency editor, nor does it rely on any transparency threshold or matte system. It is an ordinary image editor that happens to handle real transparency cleanly and uses its own compact format designed for that purpose.

The latest release significantly expands what you can do inside that editor.

File Handling Improvements

Previously, opening a PNG required a separate path (Old was: File, Open (PNG)...), from opening an .fti file. The update unifies this. From the File menu you can now open both .fti and .png files in a single dialog (File, Open...). PNGs are imported and converted into .FTI so you can start working immediately. Saving still happens exclusively as .fti, keeping the workflow focused.

File association for .fti remains in place, so double-clicking an .fti file continues to launch the editor directly.

New Editing Tools

The toolset has expanded in practical ways:

  • Pen, Color picker, Size, and Eraser still form the core painting tools, with adjustable size and proper anti-aliasing.

  • Eyedropper lets you sample any color on the canvas. Transparent pixels are detected and reported in the status bar. After sampling, the tool automatically switches back to the pen.

  • Text tool adds live text editing. Click on the canvas, type, and resize the text box as you go. Shift+Enter inserts a line break; Enter or Escape commits the text. Font size is controlled by the same size slider used for the brush.

  • Selection tool supports rectangular selections with visible handles. You can select all with Ctrl+A, delete the selection with Escape or Backspace, deselect by clicking off or switching tools, or use it as a target area for pasting.

These additions turn the editor from a pure paint-and-save utility into something closer to a lightweight daily image tool.

Copy, Paste, and Clipboard Behavior

Clipboard support is one of the more thoughtful parts of the update. Copy works on the current selection or the entire image. Paste is smart:

  • If the clipboard contains text, the editor switches to the Text tool and places an editable text box at the last mouse position.

  • If the clipboard contains an image, the image is pasted. External images (from other applications) are forced to full opacity so they replace rather than blend with whatever is underneath. Internal copies from within FTI Studio can preserve transparency if desired.

This dual behavior keeps text and image pasting predictable without requiring extra menu commands.

Undo, Redo, and Keyboard Shortcuts

A 40-level undo/redo stack is now available (Ctrl+Z / Ctrl+Y). The history is cleared when a new file is opened or a blank canvas is created, which keeps memory use reasonable.

Keyboard shortcuts cover the main actions:

  • Ctrl+C / Ctrl+V for copy and paste

  • Ctrl+A for select all

  • Delete or Backspace to delete a selection

  • Escape or Enter to add text

While the text box is active, the usual text-editing shortcuts continue to work and the global image shortcuts are correctly suppressed.

Interface and Polish

The dark theme remains consistent across menus, toolbox, status bar, and dialogs. The canvas still sits on a checkerboard background so transparent areas are easy to see. The status bar shows coordinates and, when the eyedropper is active, the exact RGB and alpha values under the cursor.

Canvas size can be changed through a simple dialog (with a soft warning above 8000 pixels on either side). Help menus explain both the .fti format and the full shortcut list.

What Stayed the Same

The core philosophy did not change. FTI Studio is still free, still Windows-only, still focused on a single simple format, and still free of layers, vectors, or complex project files.

The update simply makes the editor more usable for everyday tasks while staying true to that original design.

Who This Update Helps

Anyone who already used FTI Studio for image work will notice the difference immediately. The addition of text, eyedropper, proper selection, and reliable clipboard support removes several of the previous friction points. New users who need a lightweight Windows image editor that handles transparency cleanly now have a more complete tool without having to learn a large suite.

The official download remains here. Because the application is free and closed-source, the update is straightforward to try.

In short, the latest version of FTI Studio keeps the same identity—a native Windows image editor with transparency included—while delivering a set of practical improvements that make it noticeably more useful day to day.
